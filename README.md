# RIFT SMURFS

Loja gamer digital própria, com identidade visual original e catálogo real.

## Estado atual
- Página inicial e layout responsivo criados.
- Catálogo vazio por padrão: nenhum produto ou anúncio fictício.
- Integrações de banco de dados, login administrativo, checkout Cakto e entrega digital ainda precisam ser configuradas.

## Executar localmente
```bash
npm install
npm run dev
```

## Deploy
O projeto está preparado para Next.js na Vercel. Configure o repositório GitHub como fonte do projeto.
